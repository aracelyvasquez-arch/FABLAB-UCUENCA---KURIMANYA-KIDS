1.1 Introduction to Research & Development

a & b. Initial Project Ideas & Comparative Evaluation

During the initial brainstorming session, three main technological interventions were proposed to address social, medical, and environmental issues through rapid prototyping and digital fabrication:

1

Portable Menstrual Cramp Reliever

A wearable device combining localized thermotherapy with micro-TENS (Transcutaneous Electrical Nerve Stimulation) pulses to alleviate primary dysmenorrhea symptoms without systemic medication.

2

Modular Water Purification Device

A compact, solar-powered water filtration and UV-C sterilization system designed for low-income rural communities lacking reliable potable water access.

Selected
3

Kurimanya Kids: Smart Pediatric Orthosis

A low-cost, modular, and growth-adaptable orthotic device designed to support clubfoot (congenital talipes equinovarus) post-corrective maintenance using local FabLab materials and embedded compliance telemetry.

c. Final Selected Project: Kurimanya Kids

The team selected Kurimanya Kids as the definitive final project. Congenital talipes equinovarus (clubfoot) requires pediatric patients to wear an abduction orthosis continuously for several years after initial casting. Commercial orthotic systems imported to Ecuador cost between $250 and $400 USD and must be completely discarded every 6 months as the infant grows. Kurimanya Kids solves this through an open-source, low-cost modular design produced entirely in FabLab Cuenca using 3D-printed PETG/TPU, laser-cut anatomical straps, and embedded pressure sensors.

d. Key Conclusions of the Project Selection Process

  • High Local Social Impact: Directly tackles treatment abandonment in local pediatric populations caused by high orthosis replacement costs.
  • FabLab Material Compatibility: Uses technical polymers (PETG and flexible TPU) and digital fabrication tools available directly within FabLab Cuenca.
  • Parametric Adaptability: The modular hinge and shell structure scale dynamically with child growth, reducing long-term family expenses to simple shell replacements (~$8–$12 USD).

1.2 Website Development & Documentation Architecture

a. Website Objective

To establish an auditable, open-source technical log documenting the weekly engineering progress, code repositories, 3D CAD models, and clinical validation of the Kurimanya Kids orthotic device.

b. Site Architecture

Structured as a static multi-page website featuring a main landing page (index.html), dedicated weekly assignment modules (week01.html, etc.), and a central downloadable assets hub.

c. Folder & Directory Tree

Root level contains HTML files and datasets. Media assets are organized inside a dedicated img/ directory using normalized lowercase file naming conventions.

d. Base Template & Cover Design

Built using standard HTML5, Tailwind CSS via CDN, custom Google Typography (Space Grotesk & Inter), and Lucide SVG icons for clear visual hierarchy.

e. Key Technical Considerations

Zero dependencies on heavy JS frameworks, cross-browser CSS compatibility, lightweight asset footprint, and POSIX case-sensitivity adherence for Linux web servers.

f. Responsiveness & Adaptive Layout

Mobile-first responsive fluid grid utilizing Tailwind breakpoints (sm:, md:, lg:) ensuring optimal rendering on smartphones, tablets, and desktop displays.

g. Image Asset Management

High-resolution screen captures and photos compressed for web efficiency, linked via relative path references and enhanced with an interactive Lightbox viewer modal.

h. Standardized Weekly Format

Every weekly page maintains a unified header, numbered section dividers, visual evidence grid, technical challenges block, retrospective analysis, and footer credits.

Weekly Retrospective & Challenges

What We Learned

Configuring Git distributed version control pipelines, establishing relative path structures for web deployment, and structuring parametric design requirements for pediatric medical orthoses.

Mistakes Encountered

Initial file path broken links caused by case-sensitivity mismatches between local OS and Linux web servers, along with Git tracking rules ignoring empty asset directories.

Main Bottlenecks

Synthesizing clinical hospital data (INEC ICD-10 Q66) into actionable medical engineering requirements while maintaining strict low-cost constraints using local FabLab polymers.

Conclusions & Recommendations

Conclusions

The initial phase successfully validated both technical web documentation infrastructure and the clinical feasibility of Kurimanya Kids. Leveraging digital fabrication at FabLab Cuenca significantly lowers orthosis replacement costs for pediatric clubfoot treatment.

Recommendations

  • Maintain strict lowercase naming conventions across all media files pushed to GitHub.
  • Proceed with 3D CAD test prints in PETG and TPU to evaluate hinge structural durability.
  • Begin initial calibration tests for heel FSR pressure sensors with ESP32 microcontrollers.
